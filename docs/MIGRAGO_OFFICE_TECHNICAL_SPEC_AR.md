## نظام الصلاحيات (RBAC)
- STAFF:
  - إضافة عميل
  - البحث عن عميل
  - إضافة دفعة
  - تحميل إيصال / عقد
  - لا يمكنه الوصول للحسابات أو التقارير أو إدارة الموظفين
- ADMIN:
  - جميع صلاحيات STAFF
  - إدارة المراحل
  - إدارة الحسابات والتقارير
  - إضافة موظف جديد
  - تأكيد التحويلات البنكية

> قاعدة أساسية: ADMIN = STAFF + صلاحيات إضافية
